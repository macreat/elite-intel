# Frontend

React, TypeScript, and Vite single-page application for the business dashboard.
Provides transaction management interfaces, KPI visual cards, filtering controls, and financial analytical charts.

**Contents:**
- `src/` - React components, pages, hooks, state, and API integration code.
- `public/` - Static web assets, icons, and favicon files.

**Depends on:** Backend API running at `/api/v1` (FastAPI).
