# Machine Learning & Predictive Analytics

Machine learning research, feature extraction, demand forecasting experiments, and trained model artifacts.

**Contents:**
- `notebooks/` - Exploratory data analysis (EDA) and experimental model research.
- `features/` - Feature engineering pipelines and transformation functions.
- `models/` - Serialized trained models and evaluation artifacts.
- `experiments/` - ML experiment tracking logs and metrics.

**Depends on:** Validated transaction historical data from PostgreSQL database and `data/processed/`.
