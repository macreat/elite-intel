# Database ORM Models

SQLAlchemy database table declarations and relationship mappings.

**Contents:**
- `transaction.py` - Financial income and expense database entities.
- `category.py` - Business operational category mappings.
- `product.py` - Products and service items catalog model.
- `import_batch.py` - Historical CSV / Excel data import audit records.

**Connects to:** Database session (`db/`) and repositories layer.
