# Pydantic Schemas

Pydantic models for data validation, serialization, and API request/response typing.

**Contents:**
- `transaction.py` - Transaction creation, update, and response schemas.
- `category.py` - Category request payload validation definitions.
- `dashboard.py` - KPI summary, category metrics, and chart response schemas.
- `import_data.py` - Historical dataset import mapping definitions.

**Connects to:** FastAPI request handlers in `api/`.
